# 🦁 App de Declaração de Imposto de Renda no Excel

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte do curso **Santander- Excel com IA e Claude**, ministrado por **Felipe Aguiar**, com o objetivo de criar uma aplicação utilizando o Microsoft Excel para auxiliar na organização de informações necessárias à declaração de Imposto de Renda.

A solução utiliza recursos do Excel para estruturar os dados do contribuinte, organizar informes bancários e registrar informações relevantes de maneira prática e intuitiva.

## 🎯 Objetivos

- Desenvolver uma ferramenta organizada e funcional utilizando o Microsoft Excel.
- Facilitar o preenchimento e a consulta de informações do contribuinte.
- Centralizar dados pessoais e informações financeiras em um único arquivo.
- Aplicar conhecimentos de organização de dados, estruturação de informações e usabilidade.

## ⚙️ Funcionalidades

- **Dados do titular:** cadastro de informações pessoais e dados do contribuinte.
- **Informes bancários:** registro de instituições financeiras, valores atuais e anexos dos informes.
- **Organização de informações:** centralização dos dados necessários para auxiliar na preparação da declaração.
- **Navegação entre etapas:** interface com seções e botões para facilitar o preenchimento.

## 🛠️ Tecnologias utilizadas

- Microsoft Excel
- Recursos de formatação e organização de dados
- Estruturação de formulários e interface visual

## 📷 Demonstração do projeto

O aplicativo possui uma interface organizada em três seções principais:

1. **Titular:** informações pessoais do contribuinte.
2. **Informes:** dados bancários e valores informados pelas instituições financeiras.
3. **Notas:** inclusão de notas bancárias e extratos de holerites, facilitando a organização dos documentos financeiros.

## 📚 Aprendizados

Durante o desenvolvimento, foram praticados conceitos de organização e estruturação de dados em planilhas, criação de interfaces no Excel e construção de uma ferramenta voltada à resolução de um problema prático.

## 🚀 Como utilizar

1. Baixe o arquivo Excel do projeto.
2. Abra-o no Microsoft Excel.
3. Preencha os campos com os dados correspondentes.
4. Organize as informações financeiras e os informes bancários.
5. Revise os dados antes de utilizá-los na preparação da declaração.

## ⚠️ Observação

Este projeto possui finalidade educacional e foi desenvolvido como atividade prática de aprendizado. A ferramenta auxilia na organização das informações, mas não substitui o programa oficial da Receita Federal nem garante a conformidade fiscal dos dados preenchidos.

**Importante:** utilize apenas dados fictícios ao compartilhar capturas de tela ou disponibilizar o projeto publicamente.
